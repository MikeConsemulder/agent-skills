# `po-skills` – Product Owner Skills

Stop the feature factory: Discovery, Grilling, PRD Drafting, and DoR Linting.

| Skill | What it does | Output |
| --- | --- | --- |
| `/po-discovery` | Problem space triage & Cagan's 4 big risks | `DISCOVERY.md` |
| `/po-grill` | Adversarial interviewing on assumptions, edge cases & non-goals | `DECISIONS.md` (+ `GLOSSARY.md`) |
| `/po-draft` | Clean, INVEST-compliant stories/PRD with Gherkin acceptance criteria | `PRD.md` / `STORIES.md` |
| `/po-review` | Clean-context linter for Definition of Ready & ambiguity | Ambiguity Score + fixes |

Inspired by Marty Cagan, Teresa Torres, Claire Vo and Matt Pocock.

Works in any agent that loads `SKILL.md` skills; see the [root README](../../README.md#installation) for installation.
